# Code of Conduct

## Our Pledge
The **Looma** project (`PRIGID-WEB-CLOUD`), led by **Kpormegbe Gideon**, is committed to
maintaining a respectful, safe, harassment-free, and professional engineering environment
for all authorized contributors, reviewers, and community participants.

## Expected Behavior
- Communicate clearly, constructively, and respectfully in issues, pull requests, and reviews.
- Focus feedback on code quality, security, reliability, and user experience—never personal attacks.
- Respect project ownership, confidentiality, and security disclosure rules.

## Unacceptable Behavior
- Harassment, discrimination, hate speech, intimidation, or derogatory remarks.
- Sharing private user data, leaked credentials, or unauthorized proprietary source distributions.
- Trolling, spam, or deliberate disruption of repository discussions or CI workflows.

## Enforcement
Violations may be reported directly to the Repository Owner and Project Maintainer,
**Kpormegbe Gideon** (`prigidholdings@gmail.com` or via `PRIGID-WEB-CLOUD` repository
administrators). Authorized administrators reserve the right to remove comments, reject
contributions, revoke repository access, or ban offenders permanently.
